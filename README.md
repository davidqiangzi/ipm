# AI 产品经理专业知识系统 (AI PM Knowledge System)

## 📖 简介
本项目致力于构建并持续迭代一套为一线 AI 产品经理（AI PM）量身定制的专业知识图谱与实战指南。无论是从传统互联网产品经理转型，还是希望深度掌握企业级 AI 落地能力，本系统旨在为您提供结构化、模块化以及前沿可考的方法论体系。

## 📂 文件结构
- `AI产品经理专业知识系统_v1.4_交互课件.html`: v1.4 最新交互式课件。新增了 Generative UI、DPO 数据飞轮、安全护栏 (Guardrails) 机制，并原生集成了带有进度条的纯前端 TTS 断点续读播报功能。
- `AI产品经理专业知识系统_v1.3_交互课件.html` & `v1.2.1`: 历史归档课件。
- `AI产品经理专业知识系统_v1.4持续优化方案.md`: v1.4 优化方向记录。
- `.github/workflows/deploy.yml`: 面向 `ipm.spd100.com` 的 GitHub Actions 全量自动化部署流水线。

## 🛠 开发与维护
本项目主要通过 Markdown 文档进行迭代，更新策略侧重于**“论有所据”**（要求所有补充基于真实的官方标准及前沿学术论文）。
详细版本更新历史请参阅 [CHANGELOG.md](./CHANGELOG.md)。
