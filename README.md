# AI 产品经理专业知识系统 (AI PM Knowledge System)

## 📖 简介
本项目致力于构建并持续迭代一套为一线 AI 产品经理（AI PM）量身定制的专业知识图谱与实战指南。无论是从传统互联网产品经理转型，还是希望深度掌握企业级 AI 落地能力，本系统旨在为您提供结构化、模块化以及前沿可考的方法论体系。

## 📂 文件结构
- `AI产品经理专业知识系统_v1.2.1_交互课件.html`: v1.2.1 版本的离线全量交互式课件。涵盖大模型基础、Prompt 工程、RAG 实践、Workflow & Agent 协同、评测体系等 32 个核心章节。
- `AI产品经理专业知识系统_v1.3持续优化方案.md`: v1.3 版本的前瞻性优化和扩展方案。重点包含了面向最新企业级落地的四项核心技术产品化设计：
  1. 进阶检索：GraphRAG 与 Agentic RAG
  2. 协同范式：Multi-Agent 工程编排 (Supervisor & Swarm)
  3. 生态互联：MCP (Model Context Protocol) 协议接入与安全门禁
  4. 质量评测：基于 LLM-as-a-Judge 的自动化评测标准

## 🛠 开发与维护
本项目主要通过 Markdown 文档进行迭代，更新策略侧重于**“论有所据”**（要求所有补充基于真实的官方标准及前沿学术论文）。
